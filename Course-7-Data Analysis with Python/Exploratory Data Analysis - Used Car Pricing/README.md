## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** and **data preprocessing** using Python. It demonstrates practical skills required for a **Data Analyst / Junior Data Scientist** role, following an **IBM / Coursera-style workflow**.

---

## 🎯 Objectives

* Clean and preprocess real-world datasets
* Handle missing and inconsistent values
* Perform descriptive statistics and correlation analysis
* Visualize data to extract insights
* Validate model assumptions using residual analysis

---

## 🧰 Tools & Technologies

* **Python**
* **Pandas & NumPy** – data manipulation
* **Matplotlib & Seaborn** – visualization
* **Jupyter Notebook** – interactive analysis

---

## 📂 Tasks Performed

* ✔️ Identified and handled missing values (`?`, `NaN`)
* ✔️ Data type conversion and normalization
* ✔️ One-Hot Encoding of categorical variables
* ✔️ Descriptive statistics (mean, variance, distribution)
* ✔️ Pearson correlation & p-value interpretation
* ✔️ Residual plot analysis for model diagnostics
* ✔️ Heatmaps and pseudocolor plots for pattern detection

---

## 📊 Results & Visualizations

### 🔹 Key Results

* Missing and inconsistent values were successfully cleaned
* Categorical features converted into machine-readable format
* Strong and weak correlations identified using Pearson method
* Model assumptions evaluated using residual diagnostics

### 🔹 Visualizations Included

* 📈 **Correlation Heatmap** – strength & direction of relationships
* 📊 **Residual Plots (`sns.residplot`)** to analyze:

  * Model goodness of fit
  * Non-linear patterns
  * Heteroscedasticity (unequal variance)
* 🎨 **Pseudocolor / Heatmap Plots** – intensity-based comparisons
* 📉 **Distribution & Bar Plots** – data spread and category frequency

### 🔹 Interpretation Highlights

* Random residual scatter → good linear fit
* Curved patterns → non-linear relationship
* Funnel-shaped residuals → heteroscedasticity
* High correlation with low p-value → statistically significant
