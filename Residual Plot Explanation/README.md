# 📉 Residual Plot Analysis with Python (Regression Diagnostics)

**Residual Plot analysis**, a critical diagnostic tool in **Linear Regression**. Using Python, Matplotlib, and Seaborn, I demonstrate how residual plots help evaluate:

- Model fitness
- Presence of non-linear relationships
- Unequal variance (heteroscedasticity)

The project is designed as a **learning project**, suitable for beginners in Data Science and Machine Learning.

---

## 🎯 Learning Objectives
By completing this project, I learned how to:

- Understand and compute residuals
- Interpret residual plots visually
- Validate linear regression assumptions
- Detect model issues using `sns.residplot()`

---

## 🧠 Key Concept: Residual
Residual is defined as:

\[
\text{Residual} = \text{Actual Value} - \text{Predicted Value}
\]

Residual plots help answer:
> **Where, how, and why a regression model is making errors**
